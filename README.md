# 息间 · Offtime

一款将手机屏幕非交互时段整理成今日时间轴、趋势与记录的 Android 应用。产品与统计定义见 [DESIGN.md](DESIGN.md)。

面向用户的介绍与下载网站见 [website/](website/)；部署和更新下载文件的方法见 [website/README.md](website/README.md)。

## 构建

- 使用 Android Studio 打开本目录，安装 Android SDK Platform 35 和 JDK 17，等待 Gradle 同步后运行 `app`（最低 Android 9，目标 Android 14）。
- Windows 命令行：`gradlew.bat assembleDebug`；macOS/Linux：`sh gradlew assembleDebug`。发布包可使用 `assembleRelease` 构建，需先准备本机的 `release-signing/` 签名文件。
- Debug APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。
- 已签名的正式 APK 输出到 `app/build/outputs/apk/release/app-release.apk`。发布签名密钥和密码放在忽略目录 `release-signing/`，须单独离线备份；后续更新必须使用同一把密钥。
- 1.3.1 更新对统计做了覆盖区间校验。若旧版本曾将未知区间误算为息屏，更新后显示的历史时长可能降低；已发放的地图进度不会自动回收。
- 息屏时长只计算系统事件与已确认采集覆盖区间的交集。长时间未同步、重启和系统时钟变化造成的区间可能被舍弃；旅程仅根据可靠区间继续增长。请在不同品牌手机上核对锁屏、唤醒、重启、跨午夜和权限撤销行为。
- 应用 ID 为 `cn.archeo.offtime`，计划域名 `offtime.archeo.cn`；首版完全离线，域名不用于联网服务。

## 工作方式

需要用户在系统「使用情况访问权限」中授权。基于 Android 9（API 28）及更新版本的屏幕交互事件，前台打开时同步，后台由系统周期任务尽力同步，数据保存于本机 SQLite。未知时段不推断为息屏；事件过期、任务延迟、重启、撤销权限或系统时钟跳变会使日期显示「数据不完整」。后台同步不保证即时性。AOD 等厂商功能可能让屏幕物理亮度与系统的非交互状态不一致。

首次安装后需要经历至少一次锁屏与唤醒，才会出现可确认的区间。可在设置中清除本地记录；系统保存的使用情况事件不受此操作影响。

## 漫游地图（1.2.0 测试版）

今日页的旅程卡可打开「林间小径」。累计 10 分钟已确认息屏时间前进 1 格；到达 24、72、144、240 格可查看四处地标的明信片。进度保存在本机，重复同步不会重复计数；清除本地记录也会清除地图进度。地图是从起点到终点的本地绘制卷轴路径，显示当前位置；各地标的明信片有独立画面，新抵达时有可跳过的提示。

## 桌面小组件（1.3.0 测试版）

长按手机桌面空白处，打开「小组件」，找到「息间」并拖到桌面。组件显示当天已确认的息屏时长；无授权、尚无记录或数据不完整时会显示相应状态。点击组件进入 App。打开 App、系统后台同步或桌面请求更新时会刷新；受 Android 后台调度和桌面系统限制，不保证逐分钟实时变化。
